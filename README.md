### 📈 Lo que aprendí
Me ha costado bastante iterar entre los contenedores "item" que he creado con Javascript, ya que era necesario tanto para las imágenes como para el color de fondo del before. Otra cosa que me ha costado que quede bien es el grid en la resolución desktop, ya que los contenedores no ocupaban todo el espacio requerido, creándose márgenes gigantescos. Sobre todo el contenedor en el que cambias el tiempo (dia, semana o mes), ya que no se alineaba la altura con el grid, debido al before que contiene.
